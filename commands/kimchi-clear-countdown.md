---
description: Clear all countdowns or a specific one
argument-hint: [label]
allowed-tools: [Bash]
---

If no arguments provided, clear ALL countdowns by running:

```bash
bash ~/.claude/kimchi/widgets.sh countdown-remove-all
```

If a label is provided, remove that specific countdown:

```bash
bash ~/.claude/kimchi/widgets.sh countdown-remove <label>
```

Display the output. Do not add extra commentary.
